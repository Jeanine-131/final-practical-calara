# A Peek Into My Whimsical World

## Overview
An aesthetically adorable digital art portfolio that contains my artworks and artist profile. 

## Features
- Responsive portfolio layout
- Artwork gallery with dynamically displayed content
- Light and dark theme switch
- Theme preference saved using Local Storage
- Contact form with client-side validation
- Mobile navigation menu

## Technologies
- HTML5
- CSS3
- JavaScript
- Local Storage

## Setup
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. For the best local testing experience, use the Live Server extension in Visual Studio Code.
